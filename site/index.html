A few things
to know.

Can I download Still yet?

Yes. A Developer ID signed preview is available in GitHub Releases. Apple notarization is still pending, so macOS may block opening the download. This is a prerelease; you can also build from source with Apple’s Command Line Tools.

Which Macs does it support?

Still targets macOS 26 or later and has been tested on Apple Silicon. It uses private macOS wallpaper interfaces, so system updates may require compatibility fixes. It is distributed outside the Mac App Store.

Does it work on the lock screen?

Yes, for the signed-in session’s lock screen. It does not replace FileVault or the sign-in screen before you log in, and does not change your Mac’s authentication settings.

Does my video leave my Mac?

No. Still copies your selected files locally. The app has no account, analytics, or network service. You bring your own videos; no movie clips are included in the public source.

How do I turn it off?

Pause from Still’s menu bar menu, or choose a different wallpaper in System Settings to stop using Still entirely. Quitting the controls app alone does not stop the native wallpaper.
